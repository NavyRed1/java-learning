# ADR-0006: Concurrency moves to phase 3
Status: accepted (owner decision D1). Context: Sagar's weeks 9-12 would have held 33 of 80 topics. Decision: Threads, Virtual Threads, Java Memory Model and volatile keyword form milestone M21 at the end of phase 3, which becomes "Core Java & Concurrency". Phase 4 is functional Java plus the professional ecosystem (build, web, data, testing, logging). Sagar's Multithreading placement is an editorial reference, not a constraint; Sagar topic 25 still maps to M21 and the difference is recorded in `sagar-baseline.json`. Result: phases hold 11 / 19 / 21 / 29 topics, milestones 6 / 7 / 8 / 7, weekly load 295-555 minutes. All 28 Sagar topics remain represented.
